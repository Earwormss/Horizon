### [Chinese Scientists Confirm Existence of Glueballs](https://mp.weixin.qq.com/s/pvyNR1lN7QPx3IrpB3WtUg) ⭐️ 9.0/10

Chinese scientists leading the BESIII collaboration at the Institute of High Energy Physics \(IHEP\) have experimentally confirmed the existence of glueballs, a new form of matter predicted by the Standard Model but never before observed. After 15 years of research, the team discovered the particle X\(2370\) in 2011 and, by 2024, measured its quantum state properties consistent with glueball characteristics. Further studies revealed multiple new decay modes and determined its flavor-singlet nature, confirming that X\(2370\) is predominantly a glueball. This result, announced on August 6, is described as the most definitive experimental evidence in nearly fifty years of searching for glueballs, marking a significant milestone for testing the Standard Model.

telegram · zaihuapd · Aug 6, 07:31

**「Background」** In the Standard Model of particle physics, the strong force is mediated by particles called gluons, which themselves carry color charge and can therefore bind to each other. A glueball is a hypothetical particle composed entirely of gluons, with no quarks, and its existence has been predicted by the Standard Model but never conclusively observed. The Beijing Spectrometer III \(BESIII\) experiment, located at the Beijing Electron-Positron Collider, is a major facility for studying particle properties and has been searching for glueballs for many years.

**「Impact」** This confirmation provides the first experimental validation of glueballs, a key prediction of the Standard Model, and opens new avenues for studying the strong force and quantum chromodynamics, with potential implications for particle physics theory and computational methods.

### [Deno&\#x27;s Celld: Self-hosted Durable Objects with SQLite and S3](https://github.com/denoland/celld) ⭐️ 8.0/10

Deno has released Celld, an open-source runtime for self-hosted, distributed durable objects. Each object is backed by its own SQLite database, addressed by name, and replicated to an S3-compatible bucket you own. This extends the Durable Objects abstraction, previously tied to a single provider like Cloudflare, to any infrastructure. The project is available on GitHub under the Deno organization, and it aims to provide practical utility for distributed systems and edge computing. Notably, pull requests are disabled; contributions are accepted via git format-patch attachments to respect maintainer review time.

hackernews · calvinfo · Aug 5, 16:50 · [Discussion](https://news.ycombinator.com/item?id=49185430)

**「Background」** Durable Objects are a programming model popularized by Cloudflare Workers, where each object is a single, addressable unit of state that can handle requests and maintain consistency. Celld, developed by Deno, extends this concept to self-hosted environments: each &\#x27;cell&\#x27; is a SQLite database that is continuously replicated to an S3-compatible bucket, allowing the object to move or wake up on any machine that can restore the database from the bucket. This approach decouples the abstraction from a specific cloud provider, requiring only a binary and S3-compatible storage to run.

**「Impact」** Celld lets developers run Durable Objects on their own infrastructure, breaking the previous lock-in to a single provider like Cloudflare. It distributes objects across any number of VMs, with each object backed by its own SQLite database replicated to an S3-compatible bucket, so teams can achieve the same stateful, single-writer abstraction without relying on a managed platform. This is particularly relevant for organizations that need data sovereignty, cost control, or multi-cloud flexibility, though it is a single-tenant system and requires self-hosting expertise.

**「Community Discussion」** Commenters expressed enthusiasm for running durable objects outside a single provider, with one noting the abstraction&\#x27;s proven value and simplicity. Others asked for practical use cases and comparisons to similar systems like Temporal, Restate, Azure Durable Functions, and Cloudflare&\#x27;s workerd, indicating a need for clearer guidance on when to use Celld.
